AutoSetter for macOS (Apple Silicon / Intel), Windows x64 and Linux x64 (AppImage / deb).

Download and install the file for your operating system. A purchased license is required to activate the installed app. The first successful activation permanently binds the key to that computer. The app then verifies its signed activation locally; it makes no further licensing requests to AutoSetter. Research still contacts Google and the websites being researched.

This release has no Developer ID notarization or Windows publisher signature. macOS and Windows may block or warn about these installers; see the installation notes. Linux users may need to mark the AppImage executable or install the Debian package. SHA256SUMS.txt contains the installer checksums.

Existing activations are not remotely revocable. Copying an installer or activation certificate does not activate another computer; a separate license is needed.
